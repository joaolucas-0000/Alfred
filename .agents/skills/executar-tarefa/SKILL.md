# Executar tarefa

Quando esta skill for utilizada:

1. Identifique claramente o objetivo.
2. Verifique quais arquivos serão utilizados ou modificados.
3. Explique detalhadamente o plano.
4. Execute somente os passos necessários para a conclusão da tarefa, evitando alterações desnecessárias.
5. Mantenha as alterações dentro da pasta Alfred.
6. Verifique se a tarefa realmente funcionou. 
8. Informe quais arquivos foram criados ou modificados e as demais alterações realizadas.
9. Salve o resultado final em `workspace/saida`.
